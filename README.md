# 炉石传说（类酒馆战棋自走棋）

基于 **Unity 6** 的炉石传说酒馆战棋玩法复刻项目，个人学习用途（不商用）。

## 项目状态

开发中。当前进度：

- ✅ 美术与数据资源整理：231 随从 + 106 英雄 + 529 法术的数据资产（ScriptableObject）
- ✅ 数据清单：随从/英雄/法术中文名、数值、词条、星级（CSV）
- ⏳ 游戏逻辑（招募阶段、自动战斗）
- ⏳ 场景 UI
- ⏳ 联网对战

## 如何打开

1. 安装 [Unity Hub](https://unity.com/download)，安装 Unity 6 LTS
2. 克隆本仓库，用 Unity Hub 打开（模板：Universal 2D）
3. 首次打开等导入完成即可
